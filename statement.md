# Project Statement

## Project Title

Campus Resource Allocation & Conflict Resolution System

## Problem Statement

Educational institutions have multiple shared resources such as laboratories, classrooms, seminar halls, and equipment. Multiple users may request the same resource for overlapping time periods, which can lead to scheduling conflicts and inefficient allocation.

The proposed system automates the resource allocation process and resolves conflicts using request priority.

## Project Scope

The system manages campus users, resources, resource requests, scheduling conflicts, priority-based allocation, concurrent request processing, and database records.

The project is implemented as a Java-based command-line application using MySQL for data persistence.

## Target Users

- Students
- Faculty Members
- Campus Administrators

## High-Level Features

1. User management
2. Resource management
3. Resource request management
4. Request validation
5. Conflict detection
6. Priority-based allocation
7. Concurrent request processing
8. Database storage
9. Conflict and audit logging

## Expected Outcome

The system should allocate available resources efficiently, prevent conflicting bookings, process higher-priority requests first, and maintain reliable records of resource allocation and conflicts.
